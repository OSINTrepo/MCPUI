# Рендеринг схем

`mermaid-10.6.1.min.js` — зафиксированная версия Mermaid 10.6.1 из
https://cdnjs.cloudflare.com/ajax/libs/mermaid/10.6.1/mermaid.min.js.
Лицензия MIT находится в `MERMAID-LICENSE`.

SHA-256: `9a6dd17b7cbbc65be1fb2083fa5fd9b3577e3d4d0011a77ddcc916be58df9bfb`.

Библиотека и `report-diagrams.js` встраиваются только в HTML со схемами.
Открытие и скачивание отчёта не требуют доступа к CDN. Размер такого HTML
увеличивается примерно на 2,9 MB. Смена темы повторно строит схемы, кнопки
масштаба позволяют читать широкие графы. Ошибка одной схемы сохраняет её
исходник и не блокирует остальные.
