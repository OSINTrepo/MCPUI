# Проверка компаний США и России — 2026-09-11

Проверены Microsoft Corporation (microsoft.com) и ПАО «Магнит»
(ИНН 2309085638, magnit.com). Исправления общие для соответствующих источников
и юрисдикций; названия этих компаний не зашиты в производственный код.
Это проверка двух компаний и регрессий, а не гарантия полноты для любой компании.

## Живые прогоны и происхождение итоговых данных

Выполнено шесть полных сетевых прогонов с deepseek-flash. Числа успешных вызовов
характеризуют доступную выборку, а не долю всех существующих данных.

| Компания / прогон | Секунды | Успешные вызовы / все |
|---|---:|---:|
| Microsoft baseline | 203,5 | 44 / 52 |
| Microsoft final | 164,9 | 46 / 53 |
| Microsoft verified | 311,5 | 30 / 38 |
| Магнит baseline | 192,5 | 37 / 46 |
| Магнит final | 150,9 | 45 / 51 |
| Магнит verified | 349,1 | 15 / 42 |

Последний сетевой прогон Магнита сохранил идентичность и финансовые данные,
но потерял многие веб-источники. Контейнеры оставались healthy; доступно около
3,7 ГБ памяти. Независимый `resolvectl query` разрешал magnit.com 21 секунду,
google.serper.dev 5,25 секунды. Это наблюдаемая задержка DNS; корневая причина
внешней сети полностью не установлена, настройки DNS хоста не изменялись.

Итоговый Microsoft использует ответы `microsoft-verified`; Магнит — более полную
выборку `magnit-final` с добавлением успешного `get_finances` из `magnit-verified`.
Последняя добавка содержит ИНН, дату и путь исходного прогона. Далее оба отчёта
пересобраны с новыми проверками и сохранёнными ответами модели, без новых
сетевых запросов. В начале HTML/Markdown явно указано повторное использование
данных; манифесты содержат пути и SHA-256 источников. Сбойный прогон сохранён.

| Проверка | Microsoft: было → стало | Магнит: было → стало |

| Язык корпоративных фактов | Возможен финский текст → русский перевод с исходной цитатой | Нерелевантная Wikipedia → статья исключена из фактов |

Число таблиц плохо отражает качество: Microsoft получил SEC-финансы без увеличения
общего числа таблиц. Отвергнутый кандидат Wikipedia остаётся в журнале решения,
но его текст не используется как описание Магнита. Уверенность Магнита оставлена
средней: независимых подтверждений идентичности меньше, чем у Microsoft.

## Общие исправления

1. SEC: Corporation/Corp, точный тикер и прямой CIK; неоднозначное название
   отклоняется. Отказ SEC отличается от отсутствия совпадения.
2. Финансы SEC: сравнительные значения отнесены к собственному периоду;
   квартальные значения в 10-K не считаются годовыми, поправки учитываются.
3. РФ: точный ИНН или единственное точное совпадение имени в Checko используется
   уже на этапе идентификации. Чужие CIK/ИНН не переносятся в выбранную карточку.
4. Маршрутизация: национальные реестры выбираются по подтверждённой юрисдикции.
   Для США и РФ не вызывается испанский BORME; российская цель получает get_finances.
5. Большие финансовые ответы не обрезаются на 20 000 символах до новых лет.
   Отсутствующее значение не превращается в ноль; нули и убытки сохраняются.
6. Корпоративный HTML: читаются пользовательские теги и публичные атрибуты
   компонентов, без выполнения JavaScript; расширено обнаружение разделов.
7. Русский перевод проверяется отдельно от исходной цитаты; предусмотрен один
   ограниченный повтор перевода. Неподтверждённые цитаты и числа отбрасываются.
8. Год документа сохраняется у фактов из годового отчёта. Дубликаты удаляются.
9. Адрес реестра выводится текстом, директор сохраняется независимо от доступности
   OpenCorporates. Количество записей OpenCorporates не обозначает всё руководство.
10. Обнаружен пересказ LLM «412 млрд» при корректных 412 млн в таблице. Свободный
    LLM-комментарий под финансовой таблицей теперь исключён и на этапе запроса,
    и в рендерере. Итоговые файлы пересобраны; источники и суммы не редактировались.

## Проверки и пределы

Прошли 35 регрессионных тестов: country_entity (9), pipeline (9), corporate (8),
SEC (5), MCP client (4); также существующие проверки entity и render.
Chromium проверил схемы без сети, смену темы, масштаб и изоляцию ошибочной схемы.
HTML/PDF доступны с HTTP 200. Изменённые образы собраны и применены.

Остаются ограничения:

- Полные списки владельцев, доли, дочерние компании, составы советов/комитетов
  и история назначений не собраны. SEC-путь не покрывает все частные компании США.
- Российские МСФО группы, полный судебный/контрактный/санкционный охват отсутствуют.
  Наличие API инструмента не означает, что весь его набор методов уже включён.
- Поисковые результаты могут содержать одноимённые иностранные организации;
  ссылки из поиска не равны подтверждённым фактам о выбранном юрлице.
- Корпоративные страницы читаются с ограничением объёма, поиск не гарантирует
  обнаружение всех разделов. DNS/таймауты и платные источники ограничивают сбор.
- Все выводы модели не прошли независимый фактчекинг. Проверка цитаты подтверждает
  её наличие, но сама по себе не доказывает верность перевода и интерпретации.
- HTML сохраняет Unicode; PDF использует установленный набор шрифтов и может
  показывать неполный набор китайских и символьных глифов. Для исходных названий
  предпочтителен HTML/Markdown.

Для неоднозначных названий следует указывать официальный домен и регистрационный
идентификатор: ИНН для РФ, CIK/тикер для биржевых компаний США. Неопознанное юрлицо
должно оставаться неопознанным, а не подменяться первым похожим результатом.
