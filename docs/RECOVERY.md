## Внешние ограничения

16/17 локальных MCP-серверов отдали tools/list. Bright Data зависает на сетевой
инициализации; логи показывают EAI_AGAIN/ENOTFOUND для api.brightdata.com.
Его контейнер не равнозначен готовому внешнему API. Семь hosted endpoints не
прошли повторную проверку: ContrastAPI, DomScan, FilingFirehose, DataNexus,
BGPT, TWZRD и The Stall (соединение/таймаут либо пустой список инструментов).
Это не заявлено как успешная работа источников. Остальные три remote endpoint
(Not Human Search, CrawlGraph, Helium) отдали tools/list.

Первый диагностический timeout 12 секунд оказался слишком коротким для
холодного старта Checko/OpenOSINT; после прогрева они успешно отдали инструменты.
Локальная проверка теперь допускает 90 секунд на HTTP-операцию. Внешние сервисы
проверяются отдельно; такой тест не заменяет платные вызовы всех их инструментов.

Qwen PAYG ранее возвращал AccessDenied.Unpurchased; восстановление кода не
активирует аккаунт провайдера. Успешный live Qwen-тест использует отдельный
Token Plan. Область применения подписки описана в CHINESE_MODELS.md.
