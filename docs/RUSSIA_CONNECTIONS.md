# Связи с российскими компаниями и гражданами РФ

В UI отправьте, например:

> Собери досье по ООО «Tashsoftcom», Узбекистан, сайт tashsoftcom.uz.
> Отдельно проверь связь с российскими компаниями и гражданами РФ:
> владельцев, руководителей, контрагентов, прошлые места работы в LinkedIn,
> учредителей в ЕГРЮЛ и ЕГРИП. Отделяй факты от совпадений ФИО.

Фраза о связях с РФ включает дополнительную проверку. Она не меняет страну
целевой компании: узбекское юрлицо не перенаправляется в российский реестр
из-за упоминания России в вопросе. Без этого фокуса дополнительные запросы
не выполняются.

## Как проводится проверка

1. Руководители и участники берутся из собранных корпоративных источников.
2. Веб-поиск ищет российские компании, поставщиков, владельцев, публичные
   профили LinkedIn и кандидатов в ЕГРЮЛ/ЕГРИП. До трёх лиц, до шести
   прочитанных страниц. Поисковые сниппеты остаются зацепками.
3. Явные строки таблиц контрагентов с отдельной страной РФ сохраняются с
   датой и URL. По возможности сверяется ИНН целевой компании. Запись одного
   справочника не выдаётся за независимо подтверждённую действующую связь.
4. Модель извлекает историю работы только из прочитанного текста.
   Система проверяет URL, дословную цитату и наличие полей в цитате.
   Совпадение имени остаётся кандидатом; работодателя ещё нужно связать
   с точным российским юрлицом. Закрытые профили не обходятся.
5. NewDB проверяет доступные реестры ФНС. Состояния ожидания, ошибки и
   недостаток идентификаторов отражаются явно.

Гражданство не выводится из имени, языка, работы, домена, проживания или
регистрации ИП. В текущем разделе оно обозначается как не установленное:
автоматической идентификации гражданства по документам нет. Полная история
работы и полный перечень связей не гарантируются.

## NewDB

Проверен официальный MCP endpoint `https://api.newdb.net/mcp`, авторизация
`Authorization: Bearer …`. Токен задаётся в локальной `.env`:

```dotenv
NEWDB_MCP_TOKEN=<ваш MCP-токен>
```

```bash
python3 generator/generate.py
docker compose -f docker-compose.yml -f docker-compose.mcp.yml up -d --build --no-deps orchestrator directapi librechat
```

Для прямого использования через UI поле токена есть у сервера NewDB.
Для автоматического отчёта нужен ключ развёртывания в `.env`. В отчёт и
журнал исследования ключ не записывается; ответы очищаются от секретов.

Реальные MCP-методы: `list_newdb_methods`, `newdb_submit_request`,
`newdb_get_result`, `newdb_run_sync`, `newdb_balance`.

- `egrul`: российский ИНН юрлица (10 цифр).
- `egrul_ip`: отдельно подтверждённый российский ИНН физлица (12 цифр).
- `fns_mass_founders` / `fns_mass_leaders`: ФИО либо ИНН; это только реестры
  **массовых** учредителей/руководителей, а не полный поиск всех организаций.

Автоматический фокус ограничен этими четырьмя методами, до двух лиц и шести
запросов. Вызовы платные по тарифу NewDB. Запрос получает UUID; результат
проверяется ограниченное время. Незавершённый запрос показывается как
ожидающий вместе с ID, его можно получить через `newdb_get_result`.
По умолчанию для иностранных лиц доступны только проверки ФИО: российский
ИНН не угадывается из чужой карточки. Узбекский STIR не отправляется как ИНН РФ.

## Проверки

`tests/unit_connections.py`, `tests/unit_russia_links.py`, `tests/unit_newdb.py`
проверяют ложные совпадения, границы источников, цитаты, ошибки, маршрутизацию
страны и исключение секретов. Реальное качество оценивается отдельно на
сформированном отчёте; доступность API не является доказательством полноты.
